## 2. การ์ดเหตุการณ์ (มีทางเลือก) — 20 ใบ

ฉาก: เงินเดือนออกวันแรก ยังไม่ทันได้ดม ค่าห้อง ค่าเดินทาง ค่าข้าวรออยู่หน้าประตูแล้ว

**K-E02 คนรู้จักฝากเข้างาน**
ฉาก: ญาติบอกว่ารู้จักผู้ใหญ่ในบริษัทดัง ขอแค่ "ค่าน้ำชา" นิดหน่อย
- จ่ายค่าน้ำชา → 🪙−3, เงินเดือน +1, Echo K-X04 · 💬 "ก็เรามันไม่ใช่ลูกพระยานาหมื่น ต้องซื้อทางลัดเอา"
- สมัครตามระบบ → ⚡−2, 📖+1 · 💬 "สมัครตามระบบ แล้วก็รอตามระบบ…ไปเรื่อยๆ"

**K-E03 เพื่อนชวนลงทุนผลตอบแทน 30% ต่อเดือน**
ฉาก: เพื่อนสมัยเรียนใส่สูทมาหา พร้อมสไลด์กราฟพุ่งทะลุจอ
- ลงทุนเลย → 🪙−4, Echo K-X01 (แชร์ล่ม) · 💬 "รวยแน่ ถ้าเราเป็นคนชวน"

**K-E04 ประกันที่ไม่มีใครอยากซื้อ**
ฉาก: ตัวแทนประกันโทรมาตอนกินข้าว เป็นรอบที่สาม
- ซื้อประกันสุขภาพ + รถ → 🪙−2 ต่อบทเป็นเวลา 2 บท (↻), ได้สถานะ **มีประกัน** (การ์ดเคราะห์บางใบเบาลง) · 💬 "จ่ายเงินซื้อความสบายใจ ที่หวังว่าจะไม่ได้ใช้"
- ไม่ซื้อ เดี๋ยวค่อยว่ากัน → ไม่มีผล · 💬 "ประมาทไว้ก่อน ค่อยเสียใจทีหลัง"

**K-E05 ไปเลือกตั้งครั้งแรก** *(เริ่มโซ่ซวยซ้ำซ้อน — ผังของแจ็ค)*
ฉาก: กะลาแลนด์มีเลือกตั้งใหญ่ ป้ายหาเสียงเต็มเสาไฟจนไฟฟ้าดับ
- เลือก **พรรคคนทำงาน** → 💢−1, Echo K-X02 (บทถัดไป) · 💬 "หนึ่งเสียงของเรามีความหมาย…มั้งนะ"
